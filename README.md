# Gold AI

Gold (XAUUSD) strategy research, backtesting and execution tooling.

## Trading OS & Journal

A local web app for daily trading discipline: trading plan, gated pre-market
checklist, position sizing with hard risk rules, trade journal and a
statistical edge dashboard.

```bash
python run_trading_os.py          # or run_trading_os.bat / ./run_trading_os.sh
python run_trading_os.py --demo   # explore with sample data
```

See [`trading_os/README.md`](trading_os/README.md) for details.
